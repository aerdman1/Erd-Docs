Data analyses are project-specific on the Seven Bridges Platform. Before you can start your analysis, you need to create a project.

1. Click **Projects** in the top navigation bar and select **Create a project**.

![](https://files.readme.io/89602f1-create-a-project.png)

2. Name your project. 

> 👍 Project URL
> 
> Your project will be assigned a [**short name**](the-api#section-project-short-names) based on the name that you give it. While you may re-name your project from the project [**Settings**](doc:project-settings), you cannot change the short name after your project is created.
> 
> The **short name** is used as an ID to refer to the project when you access the Platform via the API. It also appears in the URL for the project when you access the Platform via the visual interface.

3. Set general information: 
   1. Set the **[billing group](doc:payments)** (note: for Enterprise users, the billing group is set per Division by the Division administrator).
   2. Select the [project location](doc:project-and-file-locations). The default location is AWS region **us-east-1**.
   3. (Optional) Change your [spot instance](doc:about-spot-instances) preference. The default setting is **On**.
   4. (Optional) Enable [Reuse (Memoization)](doc:about-memoization).
4. Manage advanced settings
   1. **Network access** - see [Manage Network Access Control](doc:manage-network-access-control)
   2. **File download restriction** - see [Set file download restriction](doc:define-download-restriction)

![](https://files.readme.io/287284d-create-a-project-sbg.png)

> 📘 Change the Project URL
> 
> Note that before you click **Create**, you can edit your project's URL and, by association, its **[short name](the-api#section-project-short-names)**.

5. Click **Create** to finish creating the project.
