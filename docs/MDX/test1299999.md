# Job Postings Tutorial: Using the API

_Last updated Jan 17th, 2022_

## Resources

- For help with authentication see our [OAuth 2.0](/guides/oauth-2-0) guide
- For a comprehensive description of our Job Postings API see the full [API Reference](/apis/job-postings)

## Overview

Lightcast's Job Postings API supplies data describing both the current state of the job market (data updates daily) and historic trends. Think of this API less like a search engine that provides instant answers, and more like a set of tools you can use to tell stories about the job market.

This API has two types of endpoints, data endpoints and metadata endpoints. Data endpoints operate directly on job postings, slicing and dicing the data in customizable ways. Metadata endpoints support the data endpoints by describing which fields and values are available for a given request, including metrics, filters, and facets of the data.

To demonstrate we'll walk through a hypothetical scenario in which we use the Job Postings API to solve a problem.

## Scenario

Assume we work at a college located in Minneapolis, Minnesota, and the time has come to perform a curriculum review for our Computer Science program. We know our curriculum has worked well in the past but we want to make sure our students have the most relevant education for the current job market. To find out, we'll want to talk to a handful of companies in the area that are looking to hire people in this field, and identify the types of skills they are looking for in their job candidates.

### Criteria

1. Find the top 5 companies posting for Computer Science-related jobs in our area:
 - Only look at jobs posted in Minneapolis
 - Only show the past 6 months of available data to make it more relevant
 - For our purposes we will look for companies posting for software development occupations, using 5-Digit SOC occupations for more granularity
 - We don't want to include postings that have been sourced by staffing companies, since they are not representative of the type of companies we are looking for
2. Find the top 25 skills those 5 companies are looking for:
 - Same criteria as above
 - Restrict skills down to only specialized skills asked for by the top 5 companies found above

### Finding the correct endpoint

Our first task is to identify how to retrieve the data we are looking for. We want a list of the most active companies posting for software developers; looking through endpoints documented on the [API Reference](/apis/job-postings) page it looks like the `/rankings/{rankingFacet}` endpoint will do just that.

`/rankings/{rankingFacet}` will group and rank by `{rankingFacet}`, we want to group and rank by companies so we will use a company facet.

### Looking up metadata

To find the company facet, filters, and metrics we want to use in our request we can either read through the API reference documentation or collect the information through the API's `/meta` endpoint. We'll use the `/meta` endpoint since it should have everything we need to set up our rankings requests.

There's a lot of information here, but we can identify:

- The past 6 months of available data
 - `2018-11` through `2019-04` – November 2018 through April 2019
- The facet we will want to rank on
 - `company_name` – returns company names (as opposed to company ids when using the `company` facet)
- The filters we can use to narrow our search to postings matching our criteria
 - `when` – time period filter
 - `city_name` – city name filter
 - `soc5` – 5-digit SOC filter
 - `company_is_staffing` – staffing company filter
- The metric we care about
 - `unique_postings` – the unique number of job postings matching our filter, this will indicate the number of individual positions that a company has been posting for

With this meta information we have identified the correct facet, filters, and metrics needed to find the companies we want to talk to, all we need is to find the correct values to put in the filters.

### Populating filters

We already have the time frame for our `when` filter from the `/meta` endpoint, and `company_is_staffing` is a boolean filter so we can just set that to `false` to remove any staffing companies from our search. All we need to do is look up what to put for `city_name` and `soc5`. We can do that through the `taxonomies` endpoints, which lets us explore the API's taxonomies used for filters and facets.

First up is the `city_name` filter, which uses the `city` taxonomy. We can find what the API calls Minneapolis and use that in the filter, to do so we'll search for `Minneapolis`.

### Pulling top specialized skills

From here we can find the types of specialized skills these companies are looking for with a very similar request to what we just made. Looking up skills facets in `/meta` or the API reference page we can see that there are a few different skills facets, for our purposes we will choose `specialized_skills_name`. So we'll make a `POST` to `/rankings/specialized_skills_name` endpoint. The only changes we need to make in the request body are to add a `company_name` filter, so we only pull specialized skills for those companies, and increase the response limit, so we can see the top 25 specialized skills.

## Takeaway

This API is a tool designed for enabling you to explore the job postings you care about. There is often not a single request that will give you the answer you are looking for but a series of requests that will refine your search down to exactly what you need. Below are some tips to take away from this tutorial.

- Use the `/meta` endpoint to your advantage; always look up available days and months to stay up to date on the latest data. Job postings are added and updated daily, while new months of data are available shortly after the month is over.
- Use the taxonomy endpoints to help populate your filters, all taxonomy filters require items to match exactly with what is defined in the taxonomy, this includes capitalization and special characters.
- In addition to the taxonomy endpoints you can use the results of rankings to help refine and contextualize your results when you don't know what you want to filter on up front.
- Use the full [API Reference](/apis/job-postings) documentation to discover everything the API has to offer.
