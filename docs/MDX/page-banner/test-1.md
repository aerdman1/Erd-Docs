<Callout icon="⚠️" theme="warning">
Note - General Required Permissions

The following permissions are required for specific connection parameters:

* The value supplied in **Consumer Key** must be associated with credentials that have permissions to fetch assets (see [Authorization setup](https://developer.salesforce.com/docs/atlas.en-us.chatterapi.meta/chatterapi/CR_quickstart_oauth.htm)).

* The value supplied in **User Name** must have permissions to fetch assets (see [Manage API Access](http://Manage API Access)).
</Callout>

<Callout icon="📘" theme="info">
Note - Advanced Settings

While some asset types don’t required specific advanced settings to fetch them, some of them have optional advanced settings for fetching specific data within these assets. See [Advanced Settings](/docs/salesforce#advanced-settings) for more information.
</Callout>
